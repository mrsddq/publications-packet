# Evidence Collection Checklist

This repo should collect concise proof from the strongest ML/CV projects.

| Evidence | Source |
| --- | --- |
| Model card | Each CV project `docs/MODEL_CARD.md` |
| Results table | Each CV project `docs/RESULTS.md` |
| Reproducibility notes | Each CV project `docs/REPRODUCIBILITY.md` |
| Architecture rationale | Each CV project `docs/ARCHITECTURE_RATIONALE.md` |
| Demo screenshot/sample output | `assets/` folder in each project |

Do not invent metrics. Add results only after rerunning a command and recording the setup.
